HAM International Ltd. — GitHub Pages Setup

1. Create a PUBLIC GitHub repository named:
   ham-international-ltd

2. Upload these files to the repository root:
   - index.html
   - robots.txt
   - sitemap.xml
   - .nojekyll

3. In GitHub: Settings > Pages
   - Source: Deploy from a branch
   - Branch: main
   - Folder: / (root)
   - Save

4. Your site will normally be available at:
   https://YOUR-GITHUB-USERNAME.github.io/ham-international-ltd/

5. IMPORTANT:
   Before submitting the sitemap to Google Search Console, replace
   YOUR-GITHUB-USERNAME in robots.txt and sitemap.xml with your actual GitHub username.

6. For a custom domain, use the domain in GitHub Pages settings and then update:
   - sitemap.xml
   - robots.txt
   - the HTML canonical/og:url values once the real domain is known.
